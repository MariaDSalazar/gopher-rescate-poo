# Gopher al Rescate

Juego interactivo de las **semanas 5 y 6** de *Programación Orientada a Objetos* (IFT 365, UIDE):
arrays, slices y maps en Go.

**Jugar:** https://mariadsalazar.github.io/gopher-rescate-poo/
**Código QR para proyectar:** https://mariadsalazar.github.io/gopher-rescate-poo/qr.html

![Código QR](qr.png)

## Misiones

Cada misión sube la dificultad:

| Misión | Tema | Emergencia |
|---|---|---|
| 1 | Arrays: índices, valor cero y `len` | Cortes de luz |
| 2 | Recorrer con `for range`: contador, promedio, menor y copia de un array | Calidad del aire |
| 3 | Slices: `append`, `make`, `len` y `cap` | Sala de emergencias |
| 4 | Cortes `s[ini:fin]` y datos compartidos | Tramo cerrado del metro |
| 5 | Maps: búsqueda, «coma ok», `delete` y map `nil` | Banco de sangre |
| 6 | Misión final: slice + map y cuándo usar cada estructura | Ataque a las contraseñas |

Los retos son de cuatro tipos: tocar la casilla que lee el código, predecir la salida, encontrar la línea que
falla y elegir entre array, slice o map. Después de cada respuesta se ve el porqué, la salida real de Go, el
mensaje real del error y cómo queda la memoria. Todos los códigos se compilaron y ejecutaron con go1.27.0.

Al terminar las seis misiones, el estudiante descarga su **certificado** con su nombre, aciertos y nivel alcanzado.
Solo se pide nombre y apellido; el progreso se guarda en el propio dispositivo.
